- **The web UI is rebuilt as a routed application.** One route table declares every page, stream and action; each tab is a page module and template directory named as the nav names it, and each page holds one live stream of the same shape. Markup comes only from templates and kit components, and a test renders every page and stream with markup in every field a person or peer controls. Chat follows conversations as they happen rather than polling, and the library, browse and profile lookups load in place. `ARCHITECTURE.md` describes the layout.
