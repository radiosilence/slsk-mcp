- **The UPnP port mapper runs on a supported alpine with a narrower footprint.** It moves from alpine 3.21, which reached end of life on 2026-11-01, to alpine 3.24. The install skips package scripts, the init container states its root user explicitly, the mapper runs on a read-only root filesystem with miniupnpc's libraries loaded for `upnpc` alone, and a failed mapping now logs `upnpc`'s own output. The same alpine image runs the main `slsk` Deployment's root `state` init container, so deploying this restarts the Soulseek client, which is replaced rather than rolled (`Recreate`).
