- **The UPnP port mapper logs only why it failed, and retries sooner.** A failed mapping logs only a line that begins with one of `upnpc`'s own fixed prefixes (the router's error code, no gateway found, bad arguments), reduced to printable ASCII and capped, so neither the WAN address nor an SSDP announcement any LAN device could forge reaches the log. A success logs the internal address the router forwards to, and a router that accepts a mapping but will not confirm it counts as mapped. `upnpc` now picks the LAN address facing the router itself, and a failure retries in five minutes instead of half a lease. The mapper's package-install init container and the Soulseek client's `state` init container run with read-only root filesystems.
