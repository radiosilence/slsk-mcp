- **The UPnP port mapper logs only why it failed, and retries sooner.** A failed mapping logs the one line of `upnpc`'s output that gives the reason (the router's error code, no gateway found, bad arguments), reduced to printable ASCII and capped, never the WAN address or text a LAN device could forge. `upnpc` now picks the LAN address facing the router itself, and a failure retries in five minutes instead of half a lease. The mapper's package-install init container and the Soulseek client's `state` init container run with read-only root filesystems.
