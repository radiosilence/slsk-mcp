# slsk-mcp

A Soulseek client that runs as a service: it shares a music library, fetches albums into it through sift, and is driven from a web UI or over MCP. It ships as a container image, a static Linux binary on each GitHub release, and a Pulumi package (`@radiosilence/slsk-mcp-pulumi`, in `deploy/pulumi`) that deploys that image.

## Git

- Small changes may be pushed straight to main; anything larger, and anything touching workflows, goes through a PR. PRs are squashed; merge main into a branch rather than rebasing.
- Releases go through `just release`, never a hand-edited version on main. Never push tags; CI tags and publishes when a release PR merges.
- Commits are signed.

## Changelog

`CHANGELOG.md` is generated by `scripts/changelog.py` and never edited by hand. Every change adds one fragment under `changelog.d/unreleased/<section>/`, named `<pr>-<slug>.md` and holding one `- **Lead.** Detail.` entry; a change pushed to main without a PR names its fragment by slug alone. To correct a note, edit its fragment. `just changelog --stdout` previews the result. The format is in `changelog.d/README.md`.

## Releasing

`just release patch|minor|major` (or an exact `X.Y.Z`) branches from main, bumps the slsk-mcp crate and `Cargo.lock`, `deploy/pulumi/package.json` and its lockfile, and `APP_VERSION` in `deploy/pulumi/src/versions.ts`, turns the unreleased fragments into the version and opens the release PR. The three numbers are one: the package deploys the image by `APP_VERSION`, and CI fails any commit where they disagree. Merging the PR is the release: CI pushes the image's semver tags, then publishes the Pulumi package, then creates the GitHub release with the binaries and the changelog section as notes, so nothing names an image or package that does not exist yet. A push releases only when it changes the version; `gh workflow run ci.yml` on main retries a release that failed part way. The Release workflow (`gh workflow run release.yml -f bump=patch`) opens the same PR from CI.

## Check

```sh
just check   # Cargo.lock clean, fmt --check, clippy -D warnings, tests, the Pulumi package's typecheck and tests
just fast    # what the pre-push hook runs
just fmt
```
